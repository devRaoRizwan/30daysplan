# 30 Days Challenge

A 30-day plan to build daily habits in coding, problem solving, and interview prep.

## Folder Structure

| Folder          | Purpose                                                  |
|-----------------|----------------------------------------------------------|
| `concept/`      | Notes on core CS and programming concepts                |
| `dsa/`          | Data Structures & Algorithms problems and solutions      |
| `practice/`     | Hands-on exercises and mini projects                     |
| `python/`       | Python fundamentals, tips, and scripts                   |
| `quickpicks/`   | Quick revision notes, cheat sheets, and short takeaways  |
| `sql/`          | SQL queries, practice problems, and database notes       |
| `systemdesign/` | System design concepts, diagrams, and case studies       |

## Daily Routine

1. Learn one concept (`concept/`, `python/`, `systemdesign/`)
2. Solve DSA / SQL problems (`dsa/`, `sql/`)
3. Apply it with hands-on practice (`practice/`)
4. Write a short revision note (`quickpicks/`)
